# TimeBet 阶段 0 基线

- 状态：完成（阶段 2 已在此基线上接入领域与 SQLite 持久化）
- 日期：2026-08-12
- 首发平台：Windows 10/11 x64
- 项目性质：本地优先、开源、非商业

## 产品原则

1. 不要求账号，不提供内购、充值、提现或真实商品交易。
2. 应用默认不联网、不上传数据、不收集产品遥测。
3. 用户主动开始的学习时间块是有效学习时长的权威来源。
4. 活动窗口、空闲状态和截图只用于学习回顾，不用于监控或自动判定学习质量。
5. 累计学习时长是不可消费的历史成就；可用时间余额由独立账本计算。
6. 账本采用追加写入模型，学习、兑换、挑战和修正均保留来源记录。
7. ManicTime 仅作为公开行为和架构参考，TimeBet 独立实现，不复制其闭源代码、界面或资产。

## 已采用的默认规则

| 项目 | 默认值 |
| --- | --- |
| 时间换算 | 有效学习 1 分钟获得 1 分钟可用余额 |
| 学习开始 | 必须填写本次目标 |
| 学习结束 | 必须填写完成内容或未完成原因 |
| 截图开关 | 开始时间块时询问，用户可长期关闭 |
| 截图范围 | 当前活动窗口优先，可改为指定显示器 |
| 截图间隔 | 5 分钟 |
| 截图保留 | 7 天，可改为 30 天、永久或关闭 |
| 空闲判断 | 5 分钟后提示，由用户分类，不直接扣除 |
| 挑战单次上限 | 可用余额的 10% |
| 挑战每日上限 | 3 次 |
| 最低保护余额 | 60 分钟 |
| 视觉比例 | 70% 简约工具感，30% 可爱二次元表现 |
| 默认许可证 | Apache-2.0，阶段 1 创建许可证文件 |

## 第一阶段范围

TimeBet v0.1 包含学习时间块、目标与总结、时间账本、奖励商店、基础统计、托盘和本地数据导出。活动窗口、截图时间轴和时间挑战按后续阶段接入。

第一版明确不包含：

- 账号、云同步或服务器后端
- 连续屏幕录像
- 支付、真实商品订单或用户间资产转移
- 社交排行榜
- AI 专注判断
- 动态第三方插件加载
- macOS、Linux 或移动端
