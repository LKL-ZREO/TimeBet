# TimeBet 阶段 11：本地任务执行闭环

- 状态：完成
- 日期：2026-08-19

## 本阶段交付

1. 新增独立的本地任务模型，保存任务标题、预计时长、实际投入、状态和完成时间。
2. 今日专注页新增“今日执行”区域，支持快速添加任务、设置预计分钟数和完成任务。
3. 用户可以从任务直接开始专注，学习会话保留任务关联。
4. 学习会话完成、时间入账和任务实际投入累加在同一个 SQLite 事务内提交。
5. 新增任务查询、创建和完成状态桥接命令，并为前端增加独立的任务状态仓库。
6. 任务和会话历史仍然默认保存在本机；原有时间账本、奖励、挑战和时间轴语义不变。

## 数据迁移

迁移 `005_planning_tasks.sql` 新增：

- `planning_tasks`：当前任务及其预计/实际时长；
- `study_sessions.task_id`：学习会话到任务的可选关联；
- 任务状态和会话关联索引。

旧学习会话的 `task_id` 为 `NULL`，迁移不会改写既有学习记录或账本条目。

## 新增消息协议

- `task.list`
- `task.create`
- `task.set-completed`

`session.start` 新增可选 `taskId`。只有仍处于活动状态的任务可以启动关联专注。
