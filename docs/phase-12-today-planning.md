# TimeBet 阶段 12：今日排程

- 状态：完成
- 日期：2026-08-19

## 本阶段交付

1. 任务新增可选截止日期，使用本地自然日保存。
2. 用户可以为同一个任务创建多个今日时间块，设置开始时间和计划分钟数。
3. 今日专注页展示计划总时长、实际投入、完成数量以及按时间排序的计划列表。
4. 用户可以从计划时间块直接开始专注，也可以在尚未开始时跳过时间块。
5. 时间块不能与其他未跳过计划重叠；执行中的时间块不能跳过。
6. 存在待执行时间块的任务不能直接完成，避免留下无法执行的孤立计划。
7. 专注结算、时间入账、任务实际投入和时间块实际投入在同一 SQLite 事务内完成。

## 数据迁移

迁移 `006_today_planning.sql` 新增：

- `planning_tasks.due_date`；
- `planning_time_blocks`；
- `study_sessions.time_block_id`；
- 时间块开始时间、任务关联和会话关联索引。

旧任务的截止日期以及旧学习会话的时间块关联均为 `NULL`，不会改写已有账本。

## 新增消息协议

- `planner.today`
- `timeblock.create`
- `timeblock.skip`

`session.start` 新增可选 `timeBlockId`，并校验它必须属于同时提交的活动任务。
