# TimeBet 阶段 13：本周计划与延期

- 状态：完成
- 日期：2026-08-19

## 本阶段交付

1. 新增从周一开始的七天本周计划，按日期和开始时间聚合已有时间块。
2. 本周摘要展示计划投入、实际投入、已完成数量和已跳过数量。
3. 今日专注页的安排表单新增日期，可以把任务安排到今天以外的具体自然日。
4. 未执行时间块可以调整日期、开始时间和计划分钟数；调整后重新检查有效时间块是否重叠。
5. 未执行时间块可以按相同的本地墙钟时间延期到次日，不受 UTC 偏移和夏令时换算影响。
6. 周计划卡片可以直接开始、调整、延期到明天或跳过；执行中时间块禁止移动、延期和跳过。
7. 调整或延期只改变执行安排，不会修改任务的截止日期，因此逾期信号会被保留。

## 业务规则

- 截止日期表示任务承诺，时间块表示执行安排，两者保持独立。
- 移动时间块时先从重叠检查中排除自身，再用新时间范围校验其他未跳过时间块。
- 延期保留原来的本地小时和分钟，并把自然日增加一天。
- 周汇总使用七个自然日内的时间块状态计算，计划和实际投入不会互相替代。
- 结算仍沿用阶段 12 的原子事务：学习会话、时间账本、任务实际时长和时间块实际时长一起提交。

## 数据与消息协议

本阶段复用迁移 `006_today_planning.sql` 的任务、时间块和学习会话关联结构，没有新增数据库迁移。最新架构版本仍为 6。

新增消息协议：

- `planner.week`
- `timeblock.move`
- `timeblock.defer`

`timeblock.move` 接收时间块 ID、新的 UTC 开始时间和计划分钟数；`timeblock.defer` 接收时间块 ID，并由应用层按本地日期规则计算次日安排。
