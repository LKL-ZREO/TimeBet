# TimeBet 阶段 15：本地任务关联度

- 状态：完成
- 日期：2026-09-27

## 本阶段交付

1. 学习计时运行且活动记录开启时，后台采集器保存最近一个非 TimeBet 前台窗口作为当前工作证据。
2. 计时页每五秒读取一次最近证据，显示前台进程、窗口标题、任务关联档位和判断依据。
3. 本地规则根据任务描述关键词、常见学习应用、常见分心应用和空闲状态输出“高关联”“可能相关”“可能偏离”“检测到空闲”或“无法判断”。
4. TimeBet 自身窗口不会覆盖刚才的工作窗口；超过三十秒的证据视为过期，不会继续充当当前状态。
5. 聊天和娱乐类应用即使包含任务关键词也只会标为“可能相关”，避免把讨论学习与无关使用混为一谈。
6. 新增桌面桥接命令 `session.relevance.current`，无活动会话时返回空结果。

## 隐私边界

- 本阶段只使用进程名、窗口标题和空闲状态；
- 不读取键盘输入、剪贴板、网页正文或文档正文；
- 不使用截图或 OCR 参与关联度判断；
- 不调用云端模型，也不上传任何窗口证据；
- 关联度是可解释的启发式提示，不是对用户行为的事实裁决。

## 验收范围

- 覆盖任务关键词命中、常见学习应用、常见分心应用、空闲状态和未知应用；
- 覆盖分心应用命中任务关键词时仍要求确认；
- 覆盖 TimeBet 窗口不覆盖最近工作证据；
- 覆盖桌面桥接从后台证据返回关联结果；
- 覆盖前端开始学习后显示关联度，并在暂停后停止显示。

## 后续范围

下一阶段可以基于完整会话活动片段计算“高关联/可能偏离/空闲”的时间占比，形成可保存的每日客观回顾。AI 只负责解释结构化事实；本地模型或云端模型应作为用户主动选择的可插拔提供者。
