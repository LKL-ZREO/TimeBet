# TimeBet 阶段 4：Windows 活动与截图时间轴

- 状态：完成
- 日期：2026-08-12

## 本阶段交付

1. 使用 Windows API 读取前台进程、窗口标题、窗口范围和用户空闲时长。
2. 仅在用户主动开始且处于运行状态的学习时间块内采样，暂停和结算后停止写入。
3. 每 5 秒采样，连续相同窗口在 SQLite 中合并为活动片段。
4. 时间轴按学习会话展示前台应用片段、空闲片段和本地截图。
5. 设置页可控制活动记录、截图、截图间隔、保留期和空闲阈值。
6. 截图使用 `PrintWindow`，对空白结果回退到窗口区域复制。
7. 截图通过独立 WebView2 虚拟主机只读展示，不允许前端访问任意本地文件。
8. 过期截图同时清理 SQLite 索引和本地 JPEG。

## 隐私规则

- 活动记录默认开启，截图默认关闭。
- 开始页会明确显示本次活动和截图状态。
- 截图必须同时满足：全局截图开启、本次学习明确勾选、会话正在运行、当前不是空闲状态。
- 旧会话和未明确授权的新会话都视为不允许截图。
- 首张截图也必须等待完整截图间隔，不会在开始学习后立即拍摄。
- 所有数据默认仅保存在本机，不上传、不遥测。
