# TimeBet 阶段 5：自定义奖励商店

- 状态：完成
- 日期：2026-08-12

## 本阶段交付

1. 用户可创建、编辑、停用和重新启用自定义奖励。
2. 奖励价格以整数秒持久化，界面使用分钟输入并统一换算。
3. 商城显示最新可用时间，并在余额不足时直接禁用兑换按钮。
4. 兑换前显示名称、成本和兑换后余额，必须二次确认。
5. 兑换成功后显示消费凭证，并同步侧栏、专注页和商城余额。
6. 最近兑换保留奖励名称、价格和兑换时间快照。
7. 停用奖励保留历史，不作为删除操作，也不能兑换。

## 事务语义

兑换使用 SQLite 即时写事务串行化以下步骤：

1. 重新读取奖励及其当前价格和启用状态。
2. 从追加式账本重新计算当前余额。
3. 校验余额是否足够。
4. 追加负数 `spend` 账本条目。
5. 写入奖励名称和价格快照。

任一步失败都会回滚。并发双击兑换时，后一个请求会读取前一个请求提交后的余额，不会超额消费。账本条目仍由数据库触发器禁止更新和删除。
